**Contexto:** el frontend original (App/React + Glory) quedo materializado como SPA sobre Rust; los hooks legacy seguian llamando a `/wp-json/glory/v1/*`. Se conecto cada dominio al backend Rust existente y se degradaron los dominios sin backend.

### Decisiones / gotchas

- El contrato Rust devuelve JSON plano (sin envelope `{success,data}`) y usa UUIDs; cada hook mapea al tipo del front. Los ids UUID se pasan como string en runtime dentro de tipos `number` (solo se usan como claves/igualdad, sin aritmetica).
- `habitosIniciales` de bienvenida solo se suben en la primera inicializacion del usuario (semantica original del sync manager); un usuario ya inicializado que no tenia habitos en el servidor los vera vacios hasta crear uno (la creacion persiste).
- `frecuencia` del front es objeto `{tipo}`; Rust espera string → mapeo en `habitoARequest`.
- Backend y frontend conviven en este repo; los commits del bloque se hicieron sobre la rama `main` del repo local `task`.
